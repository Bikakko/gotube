# GoTube 4.2.0 相册首页说明

4.2.0 起，根路径 `/` 不再展示业务入口首页，而是展示一个公开可浏览的相册页。

## 目录结构

相册根目录固定为项目根目录下的：

```text
gallery/
```

只支持一级子目录作为相册：

```text
gallery/
  memes/
    001.jpg
    002.gif
  reactions/
    a.png
    b.webp
```

规则：

- 每个一级子目录 = 一个相册卡片
- 目录名 = 相册标题
- 目录下第一张合法图片 = 封面图
- 目录中没有合法图片时，不显示该相册

## 支持图片格式

- `.jpg`
- `.jpeg`
- `.png`
- `.webp`
- `.gif`
- `.avif`

其他格式会被忽略，不会出现在首页，也不会被图片接口暴露。

## 更新方式

当前版本只支持手工维护图片。

你可以通过：

- `WinSCP`
- `scp`
- 服务器文件管理器

直接把图片上传到 `gallery/<相册目录>/`。

上传完成后刷新首页即可看到新相册或新图片，不需要后台操作。

## 隐蔽入口

首页保留一个弱化的隐蔽入口，点击后会跳到原隐藏路径。

当前先使用占位图挂点。后续你可以手工替换首页用的动态图片资源，让它看起来更自然。

## 安全边界

首页相册读取只允许访问 `gallery/` 下的一级目录和白名单图片文件。

接口已经做了：

- `slug` 校验
- 文件名校验
- `resolve()` 边界检查
- 非法访问返回 `404`

因此不要依赖二级目录或软链接去组织图片，这不在当前支持范围内。
