# 2026-05-01 任务 4：`www/` 目录结构重组预案

## 目标

为后续前端目录整理提供可执行迁移方案，但本轮不实际搬动目录和页面入口。

## 本次工作

- 盘点当前 `www/` 目录现状：
  - 首页、下载页、后台、播放页、实验页、共享资源平铺混放
- 盘点当前服务端依赖：
  - `server/main.py` 直接按固定 HTML 路径读取
- 盘点当前构建脚本依赖：
  - `build.js` 递归构建 `www -> www_dist`
- 产出目录重组预案：
  - `docs/superpowers/specs/2026-05-01-www-structure-migration.md`

## 预案核心结论

- 正式页面 URL 不应改变
- 应优先重组物理目录，而不是先改公开访问路径
- 推荐目标结构：
  - `shared/`
  - `home/`
  - `download/`
  - `watch/`
  - `admin/`
  - `labs/`

## 本轮不做

- 不搬迁 `www/` 目录
- 不修改 `server/main.py` 路由读取逻辑
- 不修改 `build.js` 构建流程

## 后续建议

若进入下一阶段实现，应优先从：

1. `shared/` 与 `home/` 分离
2. 下载页目录化

开始，而不是一次性搬迁所有页面。
