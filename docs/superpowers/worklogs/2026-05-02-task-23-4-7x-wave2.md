## 任务

4.7.x 第二轮修复与优化：

1. 接口分页  
2. 后台媒体列表数据库主路径化  
3. ZIP 导出流式/落盘导出  
4. CORS 白名单配置化

## 已完成

### 1. 接口分页

- `server/api.py`
  - `GET /api/tasks` 新增 `page` / `per_page`，返回：
    - `tasks`
    - `total`
    - `page`
    - `per_page`
    - `total_pages`
  - `GET /api/me/videos` 新增 `page` / `per_page`，返回：
    - `videos`
    - `total`
    - `page`
    - `per_page`
    - `total_pages`
- `server/video_library.py`
  - 新增 `list_user_video_items_page(...)`
- 前端兼容：
  - `www/download/page.js` 兼容新的 `tasks` 响应结构，不破坏旧页面加载逻辑。

### 2. 后台媒体列表数据库主路径化

- `server/video_library.py`
  - 新增 `list_admin_media_assets_page(...)`
  - 支持：
    - owner / owner_user_id
    - keyword
    - source
    - time_filter
    - page / per_page
  - 后台媒体列表主路径改为数据库分页、数据库过滤，不再先拿全量媒体对象到 Python 再切页。
- `server/admin_api.py`
  - `get_videos(...)` 在 `MediaAsset` 主路径存在时，直接走数据库分页结果。
  - 旧的磁盘扫描 `_list_all_videos()` 仍保留给无 `MediaAsset` 数据的兼容兜底。

### 3. ZIP 导出

- `server/admin_api.py`
  - `export_zip(...)` 不再使用 `BytesIO` 在内存里拼整个 ZIP。
  - 改为：
    - 临时文件落盘
    - `FileResponse` 返回
    - `BackgroundTask` 在响应完成后清理临时文件

### 4. CORS 白名单配置化

- `server/config.py`
  - 新增 `GOTUBE_CORS_ALLOW_ORIGINS`
  - 支持逗号分隔来源列表
  - 校验：
    - 必须以 `http://` 或 `https://` 开头
    - 不允许 `*`
- `server/main.py`
  - CORS 中间件改为读取 `settings.cors_allow_origins`
- `.env.example`
  - 新增示例配置说明
