# 任务 10：播放器原生焦点回归记录

## 现象

- 下载页播放模态框
- 分享播放页 `/watch`
- 后台管理页播放模态框

在用鼠标点击原生进度条后，浏览器会把焦点切到原生控件内部。

随后出现：

- 进度条被高亮
- `↑ / ↓` 被原生控件接管为进度跳转
- `Space` 不再稳定触发自定义播放/暂停逻辑

## 当前判断

这不是当前共享快捷键逻辑本身的音量计算问题，而是原生 `video controls` 在获得内部焦点后的键盘优先级变化。

## 下一步

- 先确认是否能在不破坏原生控件可用性的前提下，把焦点重新拉回视频元素或模态容器
- 如果原生控件焦点不可控，再评估是否需要对播放器外层做更明确的焦点管理或替换为自定义控制层
