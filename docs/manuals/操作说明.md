# GoTube v4.10.0 操作说明

本文档适用于自托管运行与日常维护，配置统一通过项目根目录的 `.env` 文件进行管理。

---

## 一、 快速开始

### 1.1 服务启动与停止

- **开发模式**：
  - Windows: `.\st.bat`
  - Linux/macOS: `./st.sh`
- **生产模式**（部署为 Linux 后台服务）：
  - 启动/初始化：`./wk.sh start`
  - 重启：`./wk.sh restart`
  - 查看状态：`./wk.sh status`
  - systemd 守护进程：`systemctl restart gotube`（参见 [systemd 部署指南](SYSTEMD-SERVICE.md)）

### 1.2 访问入口

- **公开相册伪装首页**：`http://your-server-ip:8000/`
- **隐藏下载页**：`http://your-server-ip:8000/{GOTUBE_HIDDEN_PATH}`（例如 `/7777`）
- **管理后台入口**：`http://your-server-ip:8000/{GOTUBE_HIDDEN_PATH}/admin`

---

## 二、 核心配置管理 (`.env`)

修改 `.env` 后需重启服务生效：

| 配置项 | 说明 | 示例/默认值 |
|---|---|---|
| `GOTUBE_HOST` | 服务监听 IP | `0.0.0.0` |
| `GOTUBE_PORT` | 服务端口 | `8000` |
| `GOTUBE_HIDDEN_PATH` | 下载页/后台弱隐藏路径 | `7777` |
| `GOTUBE_MAX_CONCURRENT` | 全局最大并发下载任务数 | `5` |
| `GOTUBE_MAX_DOWNLOADS_PER_USER` | 单用户/会话最大同时下载数（0=不限制） | `1` |
| `GOTUBE_DOWNLOAD_DIR` | 下载视频存储目录 | `./downloads` |
| `GOTUBE_COOKIES_FILE` | 浏览器 Cookies 凭据路径 | `./data/cookies.txt` |
| `GOTUBE_ADMINS` | 初始管理员账号密码列表 | `admin:your_password` |

## 三、 用户与权限说明

### 3.1 账号体系与注册门控
1. **管理员账号**：启动时自动根据 `.env` 中的 `GOTUBE_ADMINS` 同步创建，支持在后台修改密码。
2. **注册与门控**：普通用户注册需要在后台管理界面开启注册邀请码；注册成功后自动保持登录状态。

### 3.2 邀请码与存储配额 (v4.10.0)
- 在管理后台 `/admin` 的“邀请码”页面可生成注册码。
- 生成时可设定该邀请码注册账号的**存储空间配额（MB/GB）**。
- 生成后支持明文查看与一键复制。

## 四、 日常运维与更新

### 4.1 更新下载引擎 (yt-dlp)
当部分平台（YouTube、Twitter、B 站）出现解析变动或下载报错时，直接在环境内升级 `yt-dlp`：
```bash
./venv/bin/pip install --upgrade yt-dlp
# Windows: .\venv\Scripts\pip.exe install --upgrade yt-dlp
```

### 4.2 数据库自动备份
- 系统应用内置每天自动对 SQLite 数据库做冷备（`VACUUM INTO` 机制），备份文件保存在 `databackups/` 目录下，默认保留最新 3 份。

### 4.3 Cookies 管理
- 用于下载高画质或需登录权限的视频。可在后台“Cookie 管理”选项卡直接上传/更新 Netscape 格式的 `cookies.txt` 文件。

---

## 五、 排障指引

1. **缺失 FFmpeg 提示**：确保系统或 Python 虚拟环境已包含 ffmpeg 命令行工具。
2. **连接超时 / 429 限制**：检查服务器网络连接，或更新 Cookies 凭据与 yt-dlp 引擎。
3. **服务状态自检**：运行 `./wk.sh doctor` 快速检查运行环境与路径依赖。
